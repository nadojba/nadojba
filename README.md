## Projeto em destaque

### [Geja Time Tracker — Redmine](https://github.com/nadojba/geja-time-tracker)

Extensão para Chrome que facilita o acompanhamento do tempo em chamados do Redmine e o registro de horas pela API REST.

- Sessões independentes, com controles de início, pausa e retomada.
- Acesso pelo popup, painel lateral e controle integrado à página do chamado.
- Revisão dos lançamentos antes do envio ao Redmine.
- Autenticação centralizada no service worker, sem expor a chave de API ao conteúdo da página.
